# Laboratorio 4 - Conexión a una base de datos

24/09/2026

## Contenido del repositorio
En este proyecto se realizo un formulario para el registro o modificación de productos que son almacenados en una base de datos.
El laboratorio consiste en la implementación de una base de datos a través de MySql y su conexión al programa, permitiendo ver. agregar y 
modificar la información de los varios productos. Se utilizo también el concepto de interfaces, que permiten la declaración de definiciones
a ser implementadas por clases.

## Tecnologías implementadas
C#

Visual Studio

MySql
